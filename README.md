## 🚀 What I've been building

**🔍 Production RAG systems** — LangChain + adaptive chunking + OpenAI embeddings + Pinecone + re-ranking. Lifted top-5 retrieval precision from **58% → 81%** and cut hallucinated responses by over a third vs. keyword search.

**🤖 Multi-agent LLM workflows** — LangGraph agents with tool access and output guardrails. **30% faster** task completion and structured JSON validity up from **~60% → 87%** across 500+ test runs.

**📈 Sales Outbound Pipeline** *(client project)* — a 9-step MCP tool chain wiring Apollo, Clay, GoHighLevel, Instantly and HeyReach, with a buying-signal scoring engine that grades leads A–D across 13 U.S. metro markets. ~**80% less** manual list-building.

**✍️ Blog Generation Engine** *(client project)* — MCP-powered pipeline using SEMrush/DataForSEO + Claude, taking articles from **4+ hours → under 90 minutes** and growing organic keyword coverage by 25%.

**💬 [RAGWebChatBot](https://rivetmro.com/)** — production RAG chatbot (OpenRouter + Supabase vector search) with intent classification, lead capture and an analytics dashboard.

**⚡ LLM inference APIs** — async FastAPI/Flask microservices serving 3+ client deployments at **99.5% uptime** with sub-second P95 latency.
